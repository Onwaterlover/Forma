# Evidence registry

Each important algorithmic assumption, what supports it, how confident we are, and when it was last checked. **Verified** means the source was looked up during development on the date shown. **Not re-verified** means it is a well-known reference used from prior knowledge that should be checked before changing the related defaults.

Confidence: **High** = consistent systematic reviews / meta-analyses. **Moderate** = meta-analyses with notable heterogeneity, or consensus. **Low / heuristic** = practical convention or a deliberately conservative engineering choice.

## Things the app deliberately does **not** claim

- That every muscle must be trained exactly twice weekly, every set must reach failure, heavier is always better, more sets are always better, or one split is optimal.
- That rest timing must be exact, or that wearable "readiness" scores determine training.
- That short-term weight changes are fat changes, or that body fat can be estimated from photos.

## Updating this registry

When changing a default, update the row (support, confidence, date) and the corresponding test in `src/engine/*.test.ts` or `src/nutrition/*.test.ts`.
